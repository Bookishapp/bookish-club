# BRIEF4 independent review and fix verification

The independent read-only reviewer inspected the complete working-tree security, SQL, edge, and operations changes against BRIEF4, including new and ignored files. It ran 39 selected backend/security tests and five operations tests. It found no Critical issue, one Important issue, and no Minor issue requiring action.

Important finding: Supabase's project URL rewrites GET HTML responses as plain text. A confirmation form returned directly from the function would be unusable. Verified independently in Google Chrome against [Supabase platform limits](https://supabase.com/docs/guides/functions/limits). Fixed by redirecting GET to the existing website's `/join/confirm/` page, keeping the capability in the fragment, removing that fragment on load, and accepting only its deliberate POST. No paid custom domain is required.

The updated handler regression failed against the original HTML response before the fix. The website regression failed because the generated page did not yet exist, then passed against the real generated page and script. Tests cover both actions, no automatic submission on load, malformed inputs, missing confirmation, foreign or missing Origin, database errors, and failed mail after a saved decision. The existing backend suite protects one-time database decisions.

Google Chrome then exposed a second integration detail: the normal website's `no-referrer` policy makes a cross-origin form POST's Origin `null`. That first local browser POST was rejected with 403. The confirmation page now uses `strict-origin`, which sends only the website origin, with no capability in the referrer. Other pages retain their existing policy. Chrome verified both final deliberate POSTs, each with the expected website Origin and 303 redirect to the correct result. The local test used distinct localhost and 127.0.0.1 origins, the real edge handler, and the real generated website. Only the database decision and notice delivery were fixtures. No hosted records were changed. `.ted/check-join-browser.mjs`, `.ted/JOIN-CONFIRM-BROWSER.json`, and `.ted/JOIN-CONFIRM-CHROME.png` record this proof and its earlier rejected POST.

The final `npm run test:release` passed after this fix. No second independent review was requested; the author verified the fix with regressions and Chrome.
