# Landing artwork

The landing retains the approved Bookish landing v2 artwork, original gouache wall textures, and selected wordmark. Phone images are illustrative product previews. The live actions navigate to existing Bookish routes.

Bricolage Grotesque and Shantell Sans are self-hosted variable fonts. Their SIL Open Font License texts are included beside the font files. Manrope uses the site's existing font file.
