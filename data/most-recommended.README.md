# Most Saved by Readers snapshot

`most-recommended.json` is a frozen conversion of the approved research CSV, collected November 7, 2026. It contains 128 unique Open Library works across eight editorial shelves. Every retained work has at least 50 reading-list additions. Six shelves have 20 selections each, Fantasy has 18, and Cozy Mystery has 10. Twelve works below the minimum were removed from the approved selection. Counts come from the official October 31, 2026, reading-log and ratings exports. Recent counts cover October 31, 2023, through October 31, 2026. Each exported shelf record counts once, and totals are not distinct people or verified recommendations. The JSON contains book facts, aggregates, original editorial labels, source links, scores, and catalog cover IDs.

Within a shelf, books are sorted by `reader_score`, then title. Recent activity has weight 1, and older activity has weight 1/3. The score is `20 * log10(1 + weighted_readinglog_count) * Q + min(5, log2(1 + mention_count))`, where `Q = (weighted_rating_sum + 70) / (weighted_ratings_count + 20) / 5`. This is an editorial interest-and-rating proxy, with a 20-rating prior at 3.5 stars. It does not measure repeated reading. Discussion counts are factual title occurrences in a bounded Stack Exchange reading-advice sample. Their answer links are retained, and no answer text is included.

Source documentation: [Open Library dumps](https://openlibrary.org/developers/dumps), [data licensing](https://openlibrary.org/developers/licensing), and [cover guidance](https://openlibrary.org/dev/docs/api/covers). Public pages use Open Library image URLs by cover ID, show whole covers, and credit Open Library. Cover artwork is not included in this repository. The generator makes no metadata or cover requests for this page. Reader browsers request cover images directly from Open Library.

To rebuild and check the page, run `SITE_URL=https://meetbookish.com npm run build:web`, then `npm run test:web`. The generator reads this snapshot without recollecting or changing its data.
