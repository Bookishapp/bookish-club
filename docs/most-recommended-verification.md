# Most Recommended verification

The November 7, 2026, review fixes retain 128 unique works and 148 shelf entries. Each retained work has at least 50 reading-list additions. Romance, Romantasy, Thriller, Historical Fiction, Literary Fiction, and Book Club Picks each have 20 entries; Fantasy has 18, and Cozy Mystery has 10.

The production build passed with `SITE_URL=https://meetbookish.com npm run build:web`. The standard suite passed 202 checks, visibility passed 26, web passed 22, app unit tests passed 20, and the Python data-grant suite passed 19. The built app UI smoke, JavaScript syntax checks, Deno lint, TypeScript, and edge entrypoint checks passed. New regression cases failed before the fixes and passed afterward for punctuation search, low-sample ratings, and minimum activity.

Google Chrome Beta measured document and body widths at 320, 390, 541, 768, 900, and 1440 pixels, with every book detail closed and then expanded. Document widths matched each viewport, and body widths never exceeded it. Phone select text measured 16px; larger selects measured 17px. Title search, apostrophe search, mood filtering, clearing filters, empty results, keyboard focus, Skip to content, cover failure, and reading without JavaScript passed. Phone, tablet, desktop, and expanded-detail captures were inspected outside the repository. Phone layout checks used browser emulation rather than physical iOS hardware.

AccessLint live scans of the local production page reported zero violations with details collapsed and with all reading-list and discussion details expanded. Computed dropdown link colors were `#1d5a46` normally and `#7a1a2a` on hover. Against the paper base `#f3e6cf`, these give contrast ratios of 6.54:1 and 8.48:1, respectively. Moods use a named group, and discussion link names include the book title, community, and answer identifier. These scans and browser checks cover this page; they do not establish whole-site conformance or substitute for assistive-technology user testing.

Four page screenshots were removed from the repository. The pull request describes the reviewed phone, tablet, and desktop layouts without raw branch image links. The feature branch remains available for review, with no merge or deployment.
